# Gilded Glamour Suite — Recreated Frontend

This is an **original recreation** of the publicly visible MediCare landing page at:
https://gilded-glamour-suite.lovable.app/

## Languages / technologies

- TypeScript / TSX — React application code
- CSS — styling and responsive layout
- HTML — document shell
- JSON — npm/project configuration
- React + Vite — application/build framework
- Lucide React — icons

## Run

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address shown by Vite.

## Important

This ZIP does not contain Lovable's private/original source code. It is a clean, independently written recreation based on the public page structure and visible content.
